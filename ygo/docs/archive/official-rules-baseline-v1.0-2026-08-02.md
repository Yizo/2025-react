## 1. 对局与胜负

### 1.1 术语

- **决斗（Duel）**：一局。  
- **比赛（Match）**：通常三局两胜；每一局结束后可用副卡组与主卡组/额外卡组交换（见 §2）。

### 1.2 起始

- 双方 **LP = 8000**。  
- 充分洗切自己的卡组；可切洗对方卡组（注意礼仪）。双方出示并确认副卡组张数（≤15）。  
- 猜拳/掷币：胜者决定自己先攻或后攻。  
- **比赛中下一局：** 由**上一局失败者**决定谁先攻（若上局平局则再猜拳/掷币）。  
- 双方各从主卡组顶抽 **5** 张作为起始手牌（**无**重抽/换手）。  
- 先攻玩家开始第 1 个回合。

### 1.3 胜利条件（满足任一即胜）

1. 将对方 LP 降为 **0**。  
2. 对方在**应当抽卡时**无法抽卡（含抽卡阶段的规则抽，以及效果要求抽卡却抽不出）。  
3. 卡牌效果规定的特殊胜利。  

双方同时 LP 为 0 → **平局**。投降等赛制处理由比赛规程决定，引擎可另支持。

## 2. 卡组

| 区域 | 张数 | 说明 |
|------|------|------|
| 主卡组 Main Deck | **40–60** | 抽牌来源 |
| 额外卡组 Extra Deck | **0–15** | 融合/同调/超量/连接等；**不计入**主卡组 40 |
| 副卡组 Side Deck | **0–15** | 比赛中每局结束后，可与**主卡组及/或额外卡组**交换；交换前后副卡组张数必须相同 |

**额外卡组可放入：** 融合 / 同调 / 超量 / 连接等（灵摆若本身也是这些种类则进额外；普通灵摆在主卡组）。

**同名限制（组卡）：** 主卡组 + 额外卡组 + 副卡组 **合计**，同一卡名最多 **3** 张（另受禁限表约束）。  
- 卡名相同即视为同一张卡。  
- 一般按卡面印刷卡名计算。  
- 文本写「此卡名**始终视为**××」之类、组卡时即适用的名称规则 → 按视为后的名称计入。  
- 对局中**临时**改名只影响效果判定，**不改变**组卡张数统计。

官方建议主卡组尽量接近 40，便于稳定抽到关键卡。

## 3. 场地与区域

每位玩家半场（Master Rule 场地）：

### 3.1 怪兽相关

- **主要怪兽区（Main Monster Zone）×5**  
  放置：表侧攻击 / 表侧守备 / 里侧守备（不存在「里侧攻击」）。  
- **额外怪兽区（Extra Monster Zone）×2（场地中央，双方共用规则）**  
  空置时不属于任一方；有怪兽占据时属于控制者。  
  占用 EMZ 的怪兽**不计入**主要怪兽区 5 只上限。  
  用于从额外卡组特殊召唤（见 §14）。  
  每位玩家通常同时只能占用 **1** 个额外怪兽区；要通过「额外连接（Extra Link）」等才能同时占用两个（细则由引擎处理）。  
  夺取额外怪兽区怪兽的控制权时，该怪兽改放到你的**主要怪兽区**；归还时也回到对方主要怪兽区，而不是额外怪兽区。

### 3.2 魔陷相关

- **魔法与陷阱区 ×5**  
  表侧发动或里侧盖放。  
  最左、最右格在发动灵摆怪兽为魔法时，该格同时作为**灵摆区**；该卡在此期间视为魔法卡。  
- **场地魔法区 ×1**  
  每位玩家各 1 格，**可同时各有 1 张**场地魔法；**不占用**魔陷区 5 格。  
  换自己的新场地魔法时，自己旧的送入墓地（不因此强制拆掉对方场地）。  
  可盖放在场地魔法区，盖放期间不生效，翻开/发动后才生效。

### 3.3 其他

- **卡组区**：主卡组里侧放置。效果要求展示/检索卡组后，通常须再洗切放回。  
- **额外卡组区**：额外卡组里侧；自己对局中可查看自己的额外卡组。灵摆从场上「本应进墓地」时改为**表侧**加入额外（表侧额外为公开信息）。  
- **墓地 GY**：公开信息；对方可在对局中查看；**不得打乱顺序**。  
- **除外区**：被除外的卡放置处（表侧公开 / 里侧依效果不公开）。局间通常须归还除外卡以便下一场使用。

### 3.4 控制 / 持有 / 「场上的卡」

- **控制（control）：** 在你怪兽区、魔陷区、场地魔法区、灵摆区的卡。  
- **持有（possession）：** 还包括你的手牌、卡组、额外、墓地、除外、正在向你半场召唤途中的卡，以及附着在你控制的超量怪上的素材等。  
- 文本「场上的卡」通常**不包括**墓地、卡组、额外卡组。  
- 夺取控制权的卡移到新控制者半场；之后若送墓/回手/回卡组，回到**原持有者**对应区域。

## 4. 卡牌种类与读法

### 4.1 怪兽卡基本信息

- 卡名、属性、种族、等级/阶级/连接值、ATK/DEF、效果文本。  
- **通常怪兽**：无效果，描述不影响对局。  
- **效果怪兽**：有效果；里侧时通常不能使用其效果（除非效果另有规定）。

### 4.2 效果怪兽效果分类

| 类型 | 要点 |
|------|------|
| 永续效果 Continuous | 表侧在场即适用，无「发动」 |
| 起动效果 Ignition | 自己主要阶段主动发动，可有费用 |
| 诱发效果 Trigger | 在指定时点发动（含「被破坏时」等） |
| 翻转效果 Flip | 诱发的一种；文本以「FLIP:」开头；里侧翻开时发动 |
| 速攻效果 Quick | 可在对方回合响应；拼速 2 |

### 4.3 特殊怪兽大类（额外/手续）

- **连接 Link**：有连接值与连接箭头；**无 DEF，永不能守备表示**（含效果不能改守备）。  
- **灵摆 Pendulum**：可当怪兽，也可在灵摆区当魔法；有灵摆刻度与灵摆效果。  
- **超量 Xyz**：有**阶级**无等级；素材叠在下方，可「去掉素材」。  
- **同调 Synchro**：调整+非调整，等级和等于同调怪等级。  
- **融合 Fusion**：依融合素材 + 融合卡等手续。  
- **仪式 Ritual**：主卡组仪式怪 + 仪式魔法 + 祭品。

## 5. 回合结构（全阶段）

回合按固定顺序推进：

```text
抽卡阶段 Draw
→ 准备阶段 Standby
→ 主要阶段 1 Main Phase 1
→ （可选）战斗阶段 Battle Phase
→ （仅当进行了战斗阶段）主要阶段 2 Main Phase 2
→ 结束阶段 End Phase
```

### 5.1 抽卡阶段 Draw Phase

**主要行动：** 回合玩家抽 1 张。  
**抽不出则败。**

**重要例外：** 先攻玩家**第一个回合**的抽卡阶段 **不抽卡**。

抽卡后，在进入准备阶段前，可发动满足条件的陷阱/速攻等（仍受盖放回合等限制）。

### 5.2 准备阶段 Standby Phase

- 结算「在准备阶段」发生的效果/费用。  
- 无此类卡时，仍可进行合法响应后进入主要阶段 1。

### 5.3 主要阶段 1 Main Phase 1

可按任意顺序进行下列行动（均须合法）：

1. **通常召唤或通常盖放**（合计每回合 **1** 次，含上级召唤/上级盖放）  
2. **反转召唤**（次数不限，但受限制）  
3. **特殊召唤**（次数通常不限，取决于手续/效果）  
4. **变更表侧怪兽表示形式**（见 §7）  
5. **发动卡/效果**（魔法、陷阱、怪兽效果；须支付费用、满足条件）  
6. **盖放魔法/陷阱**（有空位即可）

### 5.4 战斗阶段 Battle Phase（可选）

- **不是必须进入**；场上有怪也可以不进战斗。  
- **即使没有可攻击的怪兽，也可以进入战斗阶段**（可不宣言任何攻击），以便进入主要阶段 2。  
- **先攻玩家第 1 回合不能进行战斗阶段。**  
- 若不进行战斗：从主要阶段 1 **直接进入结束阶段**（**没有**主要阶段 2）。  
- 若进行了战斗阶段（即使零次攻击）：结束后进入主要阶段 2。

战斗阶段内步骤（顺序固定）：

1. **开始步骤 Start Step**：宣言进入战斗阶段。  
2. **战斗步骤 Battle Step**：选择攻击怪兽与攻击对象并宣言攻击；可重复。  
3. **伤害步骤 Damage Step**：计算战斗结果与伤害（见 §9）；每次攻击走完伤害步骤后回到战斗步骤。  
4. **结束步骤 End Step**：宣言结束战斗阶段。

**重选攻击对象（Replay）：**  
在战斗步骤已宣言攻击后、进入伤害步骤前，若对方场上怪兽因效果发生变化（消失/新增等），发生 Replay：可用同一怪兽重选对象、改用其他怪兽攻击，或取消攻击。若改用其他怪兽，则**先宣言过的那只仍视为已宣言攻击，本回合不能再攻击**。

### 5.5 主要阶段 2 Main Phase 2

- 可做事项与主要阶段 1 **同类**。  
- 若某行动「每回合限 1 次」且在主要 1 已用过，则主要 2 **不可再用**（如通常召唤）。

### 5.6 结束阶段 End Phase

- 结算「在结束阶段」的效果。  
- **手牌上限：** 结束阶段结束时若手牌 **多于 6 张**，须弃牌至 **6** 张。  
- 然后回合结束，轮到对方。

## 6. 召唤与盖放（全手续）

### 6.1 两大类

- **每回合通常只能做一次的：** 通常召唤 / 通常盖放（含上级）。  
- **通常可多次的：** 反转召唤、特殊召唤（除非卡另有限制）。  

**召唤被无效：** 若通常召唤/特殊召唤等在「即将召唤成功」时被无效（如神之宣告），则该次召唤**不成功**。  
现行 Master Rule：被无效的召唤**一般不计入**「每回合通常召唤 1 次」、也不计入「本回合已召唤则不能发动××」等**成功召唤**条件（以 ocgcore 为准）。  
无效召唤类效果须作为该否定连锁的**连锁 1** 发动。

### 6.2 通常召唤 Normal Summon

- 从手牌以 **表侧攻击表示** 出场。  
- **禁止**从手牌以表侧守备通常召唤。

### 6.3 通常盖放 Normal Set

- 从手牌以 **里侧守备表示** 出场。  
- **不算「被召唤」**；之后可反转召唤，或因攻击/效果翻开。  
- 与通常召唤共用「每回合 1 次」。

### 6.4 上级召唤 / 上级盖放 Tribute Summon / Set

- 等级 **5–6**：先解放（祭品）**1** 只自己控制的怪兽。  
- 等级 **7+**：解放 **2** 只。  
- 里侧守备的上级放置 = 上级盖放，同样**不算被召唤**。

### 6.5 反转召唤 Flip Summon

- 里侧守备 → **表侧攻击**（不能翻成表侧守备）。  
- **盖放的同一回合不能反转召唤。**

### 6.6 特殊召唤 Special Summon

- 不经通常召唤/盖放手续，由效果或特定召唤法出场。  
- 默认表侧攻击或表侧守备（效果另有规定除外）。  
- **「特殊召唤怪兽」**（如同调/超量等）：若未经正规手续就进入墓地等，通常**不能**再被任意效果从墓地/手牌/卡组特殊召唤（须先被正确特殊召唤过）。  
- 原本在额外卡组的怪兽，若已在墓地/除外区被正规特殊召唤过，再从那里特殊召唤时：进入**主要怪兽区**，**不需要**连接箭头（见 §14）。

#### 6.6.1 融合召唤（概要）

融合素材须在融合卡指定的位置（如手牌/场上）→ 发动融合类卡 → 素材送墓（或依效果去别处）→ 从额外卡组特殊召唤融合怪。  
若结算时素材被送去别处而非墓地，融合召唤仍可成立（规则书原文）。

#### 6.6.2 仪式召唤（概要）

手牌有仪式魔法与对应仪式怪 + 足够祭品 → 发动仪式魔法 → 解放（手牌或场上，依卡）→ 仪式怪以表侧攻/守进入**主要怪兽区**（仪式怪在主卡组，不占额外）→ 仪式魔法通常送墓。

#### 6.6.3 同调召唤（概要）

场上表侧：1 只调整 + 任意只非调整（数量依该同调怪要求，可为 0），等级合计 **等于** 同调怪等级 → 素材送墓 → 从额外特殊召唤。  
**无等级**的怪兽（超量、连接等）通常**不能**作为同调素材。

#### 6.6.4 超量召唤（概要）

场上表侧、同等级素材满足「需要 × 只等级 Y」→ 素材重叠 → 超量怪叠在上方（额外区或合法主要区）。  
「去掉素材」= 将下方一张素材送墓。

#### 6.6.5 连接召唤（概要）

- 主要阶段宣言连接召唤：将场上表侧怪兽送墓作为素材；素材须符合卡面「配方」，且计入后的素材数须等于该怪的**连接值**。  
- 通常 1 只怪计 1 个素材；连接怪作素材时，可选择计 **1** 或计其**连接值**。  
- 衍生物、当作怪兽的陷阱等，只要满足配方即可作连接素材。  
- 出场位置：额外怪兽区，或**已被连接箭头所指**的主要怪兽区（含对方连接箭头指到你半场的格）。  
- 两个额外怪兽区都空时，可任选一侧；若一侧已被占用，通常使用另一侧或箭头所指区。  
- 连接怪无 DEF、不能守备。

#### 6.6.6 灵摆召唤（概要）

1. 主要阶段：将灵摆怪兽作为魔法发动到最左与最右魔陷区（灵摆区），左右各 1；在灵摆区时视为魔法卡，可适用灵摆效果。  
2. **每回合一次**：宣言灵摆召唤。灵摆召唤是**规则上的特殊召唤**（内建特殊召唤），**自身不开连锁**，但可被「无效召唤」类效果否定。  
3. 特殊召唤等级**严格介于**两侧灵摆刻度之间的怪兽（**不含**刻度两端数值）：  
   例：刻度 1 与 8 → 可特殊召唤等级 2–7。  
   若两侧刻度相同，或相差仅为 1（如 3 与 4），则**没有任何**等级可灵摆召唤。  
   来源可同时包括：手牌中任意只，以及额外卡组中**表侧**灵摆任意只（空位与规则允许范围内）。  
4. 一次灵摆召唤中出场的多只怪兽视为**同时**特殊召唤。  
5. 场上灵摆怪兽（无论在怪兽区还是灵摆区）本应进墓地时，改为**表侧**加入额外卡组。  
6. **从手牌**灵摆召唤出的怪兽进主要怪兽区即可；**从额外表侧**灵摆召唤出的怪兽：须额外怪兽区，或连接箭头所指主要怪兽区。  
7. 仪式怪等「不能用其他方式特殊召唤」的怪兽，通常**不能**被灵摆召唤。

## 7. 表示形式

三种：

1. 表侧攻击（竖放）  
2. 表侧守备（横放）  
3. 里侧守备（里侧横放）

手动变更仅限**表侧攻击 ↔ 表侧守备**；**不能**靠手动把表侧改成里侧（须有效果）。

手动变更限制：

1. 本回合刚上场的怪兽不能改。  
2. 本回合已攻击过的怪兽，在主要阶段 2 不能改。  
3. 本回合已手动变更过一次的不能再改。  

连接怪：**永远不能守备表示**（含效果也不能改成守备/里侧守备）。

**攻击资格：** 通常只有**表侧攻击表示**的怪兽可宣言攻击；守备表示不能攻击。

## 8. 魔法与陷阱

### 8.1 魔法类型要点

| 类型 | 要点 |
|------|------|
| 通常魔法 | 通常仅自己主要阶段发动，结算后多送墓；盖放后**同一回合仍可发动**（与陷阱不同） |
| 永续魔法 | 发动后留场持续生效；离场后效果通常停止 |
| 装备魔法 | 装备在怪兽上，仍占用 1 个魔陷区；装备对象被破坏/离场/变成里侧时，装备卡通常被破坏 |
| 场地魔法 | 进场地魔法区；双方可各有 1 张；许多效果对**双方**适用 |
| 仪式魔法 | 用于仪式召唤 |
| 速攻魔法 | **自己回合**可从手牌在多个阶段发动（不限于主要阶段）；若要在**对方回合**发动，必须先盖放，且**盖放的回合不能发动** |

魔法可以盖放。除速攻外：盖放**不会**因此获得在对方回合发动的权利；但非速攻魔法盖放后仍只能在自己主要阶段发动，且**盖放当回合可以发动**。

### 8.2 陷阱

- 通常须先盖放；**盖放的回合一般不能发动**。  
- 之后可在满足条件的时点发动（含对方回合）。  
- 反击陷阱拼速 3；通常/永续陷阱多为拼速 2。  
- 永续陷阱发动后可留场；反击陷阱多用于响应其他卡/效果的发动。

### 8.3 发动 ≠ 「丢进墓地」

发动必须：选择时点合法 → 支付费用 → 进入连锁 → 双方可响应 → **逆序结算**效果。  
永续/装备等可能留场；被无效、被破坏等会改变结果。

**发动被无效**与**效果被无效**不同：前者通常整次发动失败（费用已付一般不退，依卡）；后者可能留场但效果不适用。细节由脚本/引擎处理。

## 9. 战斗阶段与伤害计算

### 9.1 攻击宣言

- 通常：每只**表侧攻击表示**怪兽每回合可攻击 **1** 次（效果可改）；**不是必须攻击**。  
- 对方场上**没有**怪兽时可**直接攻击**玩家，造成等于攻击力的战斗伤害。  
- 对方额外怪兽区的怪兽也是对方控制的怪兽，存在时不能直接攻击。  
- 基本规则**没有**贯穿伤害；攻打守备且 ATK>DEF 时，通常不给对方战斗伤害（除非卡效写「造成战斗伤害」/贯穿等）。

### 9.2 伤害步骤限制（摘要）

伤害步骤中通常只能发动：

- 反击陷阱；或  
- **直接改变怪兽 ATK/DEF** 的效果；  

且多限制在伤害计算开始前。细节以官方 Damage Step 说明为准。

### 9.3 攻击里侧守备怪兽

- 在伤害步骤中将其翻为**表侧守备**，再读取 DEF 计算。  
- **翻转效果**一般在**伤害计算之后**结算；若需选择对象，不能选择已在伤害计算中被破坏的怪兽。

### 9.4 攻打表侧攻击表示（ATK vs ATK）

| 结果 | 怪兽 | 战斗伤害 |
|------|------|----------|
| 我方 ATK > 对方 ATK | 破坏对方 | 对方受到差值伤害 |
| 相等 | 双方破坏 | 无 |
| 我方 ATK < 对方 ATK | 我方被破坏 | 我方受到差值伤害 |

### 9.5 攻打守备表示（ATK vs DEF）

| 结果 | 怪兽 | 战斗伤害 |
|------|------|----------|
| 我方 ATK > 对方 DEF | 破坏对方 | **双方通常不受战斗伤害** |
| 相等 | 都不破坏 | 无 |
| 我方 ATK < 对方 DEF | 都不破坏 | **我方**受到（DEF−ATK）伤害 |

（以上为规则书基本战斗伤害；卡效果可改变。）

### 9.6 攻击力 0 的怪兽

- **ATK 为 0 的怪兽不能通过战斗破坏任何怪兽。**  
- 两只表侧攻击、ATK 均为 0 的怪兽互打：都不被战斗破坏。  
- 若 0 ATK 表侧攻击去打对方更高 ATK 的表侧攻击怪兽：0 ATK 一方仍会被战斗破坏，其控制者受到差值战斗伤害（「不能破坏别人」≠「自己不会被破坏」）。

### 9.7 规则与卡效冲突

若基本规则与卡牌效果冲突，**以卡牌效果为准**（例如效果允许一回合攻击两次）。

## 10. 连锁与拼速

### 10.1 什么是连锁

当一张卡/效果发动时，对方（或自己）可在其**结算前**响应，形成连锁。双方不再追加后，从**最后发动的那张**开始**逆序结算**。

**禁止：** 未询问对方是否连锁就直接结算效果。

一条连锁完全结算后，若仍有满足条件的诱发等，可再开**新的**连锁（不是把旧连锁再往上叠）。

### 10.2 拼速

| 拼速 | 典型 | 规则 |
|------|------|------|
| 1 | 通常/装备/永续/场地/仪式魔法；多数起动/诱发/翻转怪兽效果 | 最慢；一般不能用来「响应」已发动的效果；SEGOC 同时诱发时例外可同连锁多张拼速 1 |
| 2 | 通常/永续陷阱；速攻魔法；怪兽速攻效果 | 可响应拼速 1 或 2 |
| 3 | 反击陷阱 | 最快；只有拼速 3 能响应拼速 3 |

响应时：新开的连锁环拼速必须 **≥ 2**，且 **不低于** 上一环拼速（SEGOC 组链除外）。

### 10.3 示例（规则书）

连锁 1：暴风（拼速1）  
连锁 2：威吓咆哮（拼速2）  
连锁 3：盗贼的七道具（拼速3）  

结算：先七道具 → 威吓被无效 → 再结算暴风。

## 11. 同时诱发（SEGOC）与不可连锁的行动

### 11.1 同时发动的诱发效果如何组连锁（SEGOC）

多个**诱发类**效果在同一时点要发动时，按下列顺序组成一条连锁（同组内由控制者自定顺序）：

1. 回合玩家的**必发**诱发  
2. 非回合玩家的**必发**诱发  
3. 回合玩家的**选发**诱发  
4. 非回合玩家的**选发**诱发  

组完后，双方还可按拼速继续追加速攻效果等，再逆序结算。

**注意：**

- 在「准备阶段 / 结束阶段」等**阶段性时点**各自发动的效果，通常**各自开连锁**，不适用把它们全塞进同一条 SEGOC（以引擎/现行裁定为准）。  
- 同一连锁中，从手牌特殊召唤自身的诱发，通常**只能发动其中一张**（如神属与托拉戈迪亚不能同连锁各跳一张）。

### 11.2 不能被连锁的行动 / 与「无效召唤」的区别

以下**不是**「效果发动」，因此**不能**用普通连锁去「响应这个动作本身」：

- 召唤 / 特殊召唤的出场手续（含通常召唤、灵摆召唤等）  
- 解放（祭品）、支付费用  
- 变更表示形式  

简记：**不能对「费用 / 改表示 / 召唤动作」开普通连锁。**

**但是：** 存在专门时点「怪兽即将被召唤时 / 召唤成功时」——例如神之宣告、神之警告在「即将召唤」时发动并**无效召唤**。这不是对「召唤动作」做拼速连锁，而是规则允许的**召唤否定窗口**。灵摆召唤作为内建特殊召唤，也可被此类效果否定。

### 11.3 超量素材补充

- 成为超量素材的怪兽**不视为场上的卡**。  
- 超量怪兽离场时，其素材一律送入墓地。  
- 超量怪兽被里侧化或被夺取控制权时，素材通常**仍附着**，不因此送墓。

### 11.4 「离开场上」

怪兽因送墓、除外、回手、回额外等可视为离开场上并可能诱发；但若被**洗回主卡组**或**变成超量素材**，则通常**不会**发动「离开场上时」类效果。

## 12. 优先权与公开信息

### 12.1 优先权

- 每个阶段/步骤开始时，**回合玩家拥有优先权**，可先发动卡或效果。  
- 无优先权时，对方一般不能主动发动（自动诱发/翻转等除外）。  
- 回合玩家可：发动效果，或**让渡优先权**。  
- 进入下一阶段/步骤时必须让渡；实务上「我结束此阶段」即表示让渡，对方可说「在结束前发动…」。  
- 一张卡发动后，以及每阶段/步骤结束时，优先权传给对方。

### 12.2 公开信息（必须如实告知）

- 双方手牌张数、主卡组张数、额外卡组张数、墓地内容、当前 LP、额外卡组**表侧**卡、表侧除外卡均为公开信息；被询问时须如实告知。  
- 墓地内容为公开信息；**实际翻看**对方墓地卡牌时应先征得同意，且**不得打乱顺序**。  
- 自己的额外卡组（含里侧）自己可查看；对方不能查看你额外卡组的**里侧**卡，也不能看你的手牌内容/主卡组顺序。  
- 里侧盖放的魔陷/怪兽、里侧除外：内容不公开。

### 12.3 双方同时执行选择时

如「双方各选 1 只怪兽」：由**回合玩家先选**，再由对方选。

## 13. 禁限卡、衍生物、术语

### 13.1 禁限卡

- 禁止：0 张  
- 限制：最多 1  
- 准限制：最多 2  
列表定期更新，正式比赛必须遵守。

### 13.2 衍生物 Token

- 由效果产生；不进卡组。  
- 只能在场上；离场则直接移除，不进墓地/手牌/卡组等（除非效果另述）。  
- 占用怪兽区；表示形式须可区分攻/守；**始终表侧**（表侧攻击或表侧守备），不能里侧。  
- 视为通常怪兽；**不能**作为超量素材。  
- 可作为连接素材（若满足条件）。

### 13.3 关键术语

| 术语 | 含义 |
|------|------|
| 破坏 Destroy | 因战斗或「破坏」效果送墓等；**解放、作为费用送墓、返回手牌/卡组不算破坏** |
| 丢弃 Discard | 从手牌送墓（效果或结束阶段调整手牌） |
| 送去墓地 Sent to GY | 破坏/丢弃/解放等都会「送墓」；但**除外区的卡再放到墓地**通常不视为「被送去墓地」 |
| 效果 Effect | 卡上写的特殊能力；**费用不是效果**；特殊召唤怪兽的「召唤条件说明」通常也不是效果 |
| 装备卡 Equip Card | 含装备魔法，以及装备在怪兽上的陷阱/怪兽；装备后的陷阱通常仍是陷阱，装备后的怪兽通常视为装备魔法 |
| 直接攻击 | 攻击玩家而非怪兽；伤害通常等于 ATK（效果可允许有怪时直接攻击） |
| 战斗伤害 / 效果伤害 | 战斗产生的伤害 ≠ 卡效造成的伤害；文本若只写其一则不相等同 |
| 战斗 / 曾战斗 | 从宣言攻击或被攻击起进入「战斗中」；文本要求「曾战斗」时，通常须到达伤害计算；攻击在伤害计算前被取消则通常不算「曾战斗」，但仍算已宣言攻击 |
| 除外 Banished | 与场地区分开放置；通常下一场决斗前需归还 |
| 连接 / 互相连接 | 箭头指向某怪兽则「连接」；两只连接怪箭头互指则「互相连接」 |

### 13.4 指示物 / 硬币 / 骰子

依卡需求准备；无效果允许则不能放置指示物。

## 14. Master Rule 2020/2021 关键修订（现行实现应对齐）

相对「新大师规则」初期：

1. **从额外卡组（里侧）特殊召唤融合 / 同调 / 超量：**  
   可放到**额外怪兽区**或**任意空主要怪兽区**（**不需要**连接箭头）。  
2. **连接怪兽**，以及额外卡组中**表侧灵摆怪兽**的特殊召唤：  
   仍须 **额外怪兽区**，或 **连接箭头所指** 的主要怪兽区（含对方箭头指到你半场的格）。  
3. **从墓地/除外**再次特殊召唤「原本在额外卡组」的怪兽时：进入主要怪兽区，**通常不需要**连接箭头。  
4. 灵摆区并入最外侧魔陷区（见 §3）。  
5. 仍为陷阱且当作怪兽的「陷阱怪」：现行修订下**不再额外占用**一个魔陷区（以 ocgcore/现行裁定为准）。  
6. 怪兽因效果回到额外卡组**里侧**时：除非文本写明，否则通常不发动「离开场上」类效果。  
7. 召唤被无效时，一般不计入「成功召唤」相关的次数/发动条件（见 §6.1）。

## 15. 标准玩法流程（对局怎么打）

按官方流程，一局应这样进行：

```text
准备：组合法卡组 → 洗切 → 决定先后手 → 各抽 5
        ↓
先攻回合：抽卡阶段（不抽）→ 准备 → 主要1
        → 不能进战斗 → 结束阶段（手牌>6则弃到6）
        ↓
后攻回合：抽1 → 准备 → 主要1
        →（可）战斗（可无攻击，仅为进主要2）→（若进过战斗）主要2 → 结束
        ↓
双方交替直到胜负条件达成
```

**主要阶段里玩家实际在做什么：**

1. 通常召唤/盖放（每回合至多一次）或特殊召唤  
2. 盖/发动魔陷、发动怪兽效果（形成连锁）  
3. 改变表示形式（受限制）  
4. 决定是否进入战斗；战斗里反复「宣言攻击 → 伤害步骤」  

**客户端正确玩法体验应对齐：**

- 引擎提示可选项（可召唤的卡、可发动的效果、可连锁的卡）  
- 玩家点选 → 提交 Response → 引擎结算 → 更新场地/LP/手牌  
- 而不是：任意拖卡上场再本地比 ATK
